🐾 Sistema de Gestión para Peluquería Canina
Este proyecto es una aplicación de escritorio desarrollada en Java, que permite gestionar de manera sencilla una peluquería canina.

Funcionalidades principales:
Agregar, editar y eliminar mascotas.


Relación uno a uno (One-to-One) entre cada mascota y su dueño.

Almacenamiento de datos mediante una base de datos relacional (por ejemplo, MySQL o PostgreSQL).

Interfaz amigable para facilitar el uso del sistema.
